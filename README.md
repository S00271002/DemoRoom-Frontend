# DemoRoom Frontend

An Angular app for sharing music demos, uploading new versions and leaving comments on each recording.

## Run locally

1. Start the [DemoRoom backend](https://github.com/S00271002/DemoRoom) on port 3000.
2. Run `npm ci` and then `npm start` in this repo.
3. Open [localhost:4200](http://localhost:4200).

Create a band through the backend before using the Create Demo form.
